# PoE 2 Desktop Clock

Десктопный трекер стоимости валюты и выбранных публичных вкладок PoE 2. Основное приложение показывает виртуальные часы с общей оценкой в Divine Orbs; консольный проект оставлен только для диагностики и ручной проверки API.

## Запуск

```powershell
.\run.ps1
```

Только проверить сборку:

```powershell
.\run.ps1 -BuildOnly
```

Для прежних диагностических команд (`status`, `debug-frame`, `currency`, `public`, `worth`):

```powershell
.\run-debug.ps1
```

## Настройка в Desktop-приложении

1. На странице «Настройки» укажите `AccountName` (это имя аккаунта с дискриминатором, например `SherlockDmt#3728`) и выберите лигу.
2. Нажмите «Выбрать область Currency-вкладки», откройте в игре именно вкладку Currency и выделите её область.
3. Нажмите «Откалибровать слоты» и при необходимости поправьте найденные рамки. Настройка сохраняет разметку 33 слотов.
4. Сделайте восемь выбранных вкладок публичными и задайте им точные технические имена, показанные в настройках: `~price 1001 mirror` … `~price 1008 mirror`. Имя вкладки — способ найти её через Trade API; каждый предмет в такой вкладке должен наследовать её цену по умолчанию, без индивидуальных цен.
5. На главной странице нажмите «Обновить данные». Это выполнит точный, но небыстрый опрос публичных вкладок и обновит виртуальные часы.

В настройках доступны частота проверки Currency-вкладки (2 или 3 кадра в секунду), фоновое обновление публичных вкладок, его интервал (не меньше 10 минут), срок актуальности цен и запуск в свёрнутом виде.

## Как обновляются часы

Когда игра и откалиброванная Currency-вкладка доступны, приложение делает снимок выбранной области 2–3 раза в секунду. Сначала оно сравнивает только зоны цифр стеков. OCR и пересчёт выполняются лишь когда эти зоны изменились. Раз в секунду дополнительно проверяется геометрия вкладки: поэтому пустая открытая Currency-вкладка тоже определяется корректно. При закрытой вкладке последнее валидное значение сохраняется, а на часах появляется соответствующий статус — нули не подставляются.

Публичные вкладки не опрашиваются на каждом кадре: это отдельная точная операция Trade API. Последний её результат объединяется с последним успешным сканированием Currency-вкладки. Если Trade API вернул неполный результат, слишком много листингов или устаревшие данные, интерфейс помечает общую оценку как неполную, а не выдаёт её за точную.

## Структура решения

```text
src/
  Poe2DesktopClock.Domain                 Правила продукта и value objects
  Poe2DesktopClock.Contracts              DTO для границ приложения
  Poe2DesktopClock.Application            Контракты пользовательских сценариев
  Poe2DesktopClock.Infrastructure.PoeApi  Адаптеры Trade API и poe.ninja
  Poe2DesktopClock.Infrastructure.Storage JSON-хранилища настроек
  Poe2DesktopClock.Infrastructure.Windows Захват окна, OCR, Win32 и калибровка
  Poe2DesktopClock.Desktop                Основное WPF-приложение
  Poe2DesktopClock.ConsoleDebug           Отладочная консоль
```

`Domain` не зависит от UI, Win32, OCR, сети или application-контрактов; здесь лежат только правила продукта. `Contracts` содержит DTO для границ приложения: настройки, снимки и статусы. `Application` содержит use case-контракты. HTTP- и JSON-адаптеры независимы от Windows и могут работать в `net8.0`; в Windows-сборке остаются только platform-specific части. WPF и инфраструктура зависят от application-контрактов, а граф конкретных зависимостей собирается в `App`, не в `MainWindow`.

Старые калибровки и настройки публичных вкладок продолжают читаться из `%LOCALAPPDATA%\Poe2DeskTracker`, поэтому перенос проекта не сбрасывает уже сделанную настройку. Новые настройки Desktop-приложения хранятся в `%LOCALAPPDATA%\Poe2DesktopClock\settings.json`.

Приложение не читает память игры и не отправляет в неё ввод. Для работы захвата требуется Windows 10 1903+ x64.
